# @openmirai/intl-runtime

Runtime primitives for loading, validating, formatting, and recovering Mirai
Intl catalogs. This package is intended for advanced integrations and is used
by [`@openmirai/intl-i18next`](https://www.npmjs.com/package/@openmirai/intl-i18next).

## Install

```sh
npm install @openmirai/intl-runtime
```

Public entry points include:

- `@openmirai/intl-runtime` — core runtime APIs.
- `@openmirai/intl-runtime/node` — Node.js helpers.
- `@openmirai/intl-runtime/react` — React bindings.
- `@openmirai/intl-runtime/react-i18next` — typed i18next bindings.

The package is ESM-only and supports Node.js 24 (`>=24 <25`).

## Documentation

See the [Mirai Intl repository](https://github.com/openmirai/mirai-intl) for
catalog generation, runtime setup, recovery behavior, and CI documentation.
