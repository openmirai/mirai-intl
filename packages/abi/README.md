# @openmirai/intl-abi

The stable catalog, descriptor, diagnostic, and wire contracts used by Mirai
Intl. This is a lower-level package for compiler, runtime, and tooling authors;
most applications should install [`@openmirai/intl`](https://www.npmjs.com/package/@openmirai/intl)
instead.

## Install

```sh
npm install @openmirai/intl-abi
```

The package is ESM-only and supports Node.js 24 and later (`>=24`). Its public entry
point is `@openmirai/intl-abi`.

## Documentation

See the [Mirai Intl repository](https://github.com/openmirai/mirai-intl) for
the compiler, runtime, Next.js, Vite, and setup documentation.
